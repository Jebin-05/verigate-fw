`raw/` and `processed/` are git-ignored. Reproduce with `verigate-train data fetch && verigate-train data sbom`:
the fetcher downloads every pinned OpenWrt (release, target) package manifest from `sources.yaml` into `raw/openwrt/`
(with the upstream release date), `data sbom` converts each to a CycloneDX 1.5 SBOM under `processed/sboms/` and
writes `processed/index.json`. `MANIFEST.sha256` records the hash of every file so results are reproducible without
committing the data. Vulnerability data (OSV records, EPSS snapshots, KEV) is cached under `processed/vulndb/` — copy
that directory to a demo machine and set `VULN_CACHE_ONLY=true` to run offline. The tampered image set is generated by
`verigate.ml.data.mutate` (P6, documented mutations, fixed seed).
